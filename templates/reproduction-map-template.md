# Reproduction map

Every reportable result in the paper / project — table row, figure curve, ablation entry — has one row in the table below. The row captures everything needed to regenerate that result deterministically: the entry-point command, the config / flag overrides, the checkpoint, the seed, and the produced log file.

If a result is not in this table, it is not reproducible by definition.

## Conventions

- **Result ID** is a short stable handle (e.g. `T1.R3` = Table 1 row 3, `F2A` = Figure 2 panel A). Use the paper's published numbering once finalized.
- **Command** is one runnable line, copy/pasteable. If a setup script must be run first, link it.
- **Config / overrides** lists CLI flags or config-file diffs that differ from the defaults. Empty if defaults are used.
- **Checkpoint** is the relative path or short hash of the model used. For training-time results (loss curves), use `train_run/<run_name>` instead.
- **Seed** is the integer seed (or "N/A" if a result is averaged across seeds — note the seed range in the row).
- **Log** is the relative path to the produced log file or metric JSON. Should be auto-generated by the command.
- **Hardware** captures GPU model + count if results depend on GPU nondeterminism.

## Table

| Result ID | What | Command | Config / overrides | Checkpoint | Seed | Log | Hardware |
|---|---|---|---|---|---|---|---|
| `T1.R1` | <short description> | `bash scripts/<entry>.sh ...` | (defaults) | `save/<run>/<step>.pt` | 42 | `save/<run>/<log>.log` | 1× <gpu> |

| `F2A` | <figure description> | `bash scripts/eval_sweep.sh && python scripts/plot/<fig>.py` | ... | ... | seeds 1-5 averaged | `figures/<fig>.pdf` | 1× <gpu> |

## When the table moves

- A result is added: append a new row with all 8 fields filled. Do not commit a row with placeholders.
- A result is updated (config tweak, new checkpoint): update the existing row in place. Note the change in the PR description.
- A result is dropped: remove the row. Don't leave dead entries.

## Verification

A clean clone + `uv sync` + each `Command` cell, run sequentially, should reproduce every `Log` cell to within documented numerical tolerance (state the tolerance per metric if non-trivial — e.g. "FID stable to ±5; R-precision stable to ±0.02").

This file is the contract; deviations from it are bugs.
